# 功能 PI 筛选

以用户实际目标和输入为准。流程配置见 [domain.json](domain.json)，输入模板见 [run-spec.template.json](run-spec.template.json)、[input-columns.csv](input-columns.csv)，来源映射与准备方式见 [NOTES.md](NOTES.md)。本交付提供工作流配置和准入约束，不含已完成的科研筛选结果。

## 输入与状态

从 `inputs/pi/run-spec.json` 读取目标；目标性质、单位、形态、测试情境和化学范围未明确时返回 `needs_input`，不能默认优化 Tg。模板中的 `null` 是未知，不是零、无限制或默认通过。

读取实际文献、测量记录和核验过的单体池。无数据时交付缺项清单和空表头；不填合成数据、模型猜值或历史其他材料数据。每阶段保存 `status/input_hash/version/results/evidence/warnings/next_step`，状态为 `completed/failed/needs_input/needs_review/unsupported/skipped`。`input_hash` 为相对路径到文件字节 SHA-256 的对象，只覆盖实际消费的文件；无可读输入时为 `{}` 并登记缺失，不能伪造哈希。软件/数据版本放入结果元信息。阶段完成与科学目标通过分别记录。

## 证据准入

- 身份链为 `paper_id → sample_id → formulation_id → structure_ids → measurement_id`，模拟另加任务 ID，预测另加模型版本。
- 保存正文/SI、页码、图表/样品定位和原始值/单位；题录不是全文。作者报告与独立图读是同一实验的不同证据，不能双计样本。
- 区分 PAA、最终 PI、共混、共聚、复合与碳化材料；分子量须记录测量对象、方法、校准体系。黏度不冒充绝对分子量。
- 实验标签只能来自实际发表实验。模拟与预测独立保存，不能填入实验缺值。
- T5/T10 必须明确气氛、基准和条件。未达失重阈值记录删失；终温不作为阈值温度。图线身份/定标不清、图表冲突进入复核，不猜数值。未知气氛不能混入明确气氛主训练集。
- MinerU 负责解析；WebPlotDigitizer 首版为人工辅助。使用真实定标项目和点列，不承诺全自动曲线识别。

## 单体与候选

PubChem 或文献用于身份线索，RDKit 用于结构规范化；缩写、异构体和角色冲突须隔离。结构合法仅是必要条件。候选身份包含规范单体、二酐/二胺角色、路线和有意义配比；别名、列顺序、无意义小数细分不新增候选。

逐条检查官能团当量、组成和、稳定性、可获取性、加工依据和项目排除条件。无采购/合成/成纤证据记未知；不把“相近体系能做”当作本候选已可做。

原需求为 **10000—100000 组有效去重候选，至少 10000 组**。数量与预测可信度分别验收。缺单体池或强约束后数量不足就报告未通过；不降低门槛、不偷偷放宽约束、不把演示候选写成完成结果。

## 模型与推荐

先解决同实验重复，再按论文/实验家族分组，并做结构家族留出。所有预处理和调参限于训练折；固定测试集不参与选型。报告基线、误差、样本量、预测区间覆盖/宽度、适用域和外推。模型验收标准未定义时不能宣布通过；随机划分高分不替代跨来源验证。

模型未通过时可交付证据目录或探索候选，不给已验证精确排行。区间大量重叠不强排名；特征重要性不等于机理因果。

最终候选检索完整组合、别名、论文和专利，区分具体报道/实施例、概括列举、近邻和本次范围内未发现。保存检索日期、范围与缺口。只改比例不算新体系，未查完不能标记新颖性通过。推荐卡将实测、预测、模拟以及已支持解释/待验证假设分开写。

## 可选模拟与工具边界

机理模拟默认关闭，关闭时文献主线可继续。开启前必须有 PI 建链、序列/端基、拓扑、电荷/力场、目标性质协议、资源与预算；缺项时停止该分支并记录原因。

Packmol 仅装填已有分子坐标；LAMMPS 执行给定模型，均不自动提供 PI 拓扑和可信参数。已部署的 LJ 演示只验证接口链路。PI Tg 还需平衡、多初态/速率敏感性、稳健转折和隔离参照；无转折不强拟合，原始 MD Tg 不等于实验 Tg。T5/T10 不能由单个键能或短反应轨迹直接换算。

CP2K/DeePMD-kit/DP-GEN 是有独立预算的可选后续路线，不能因没有经典势就自动训练。原子势训练标签是能量/力/应力，不是 Tg/T5。主动学习的候选层与构型层分开；预算耗尽不代表科学收敛。

优先复用检索、解析、身份查询和异步计算接口。RDKit、SQLite、枚举、统计、代理训练、拟合、排序和图表保留普通 Python 工作节点，不逐项新建 MCP。未知接口返回未验证或 `unsupported`，不编造工具名可调用。
