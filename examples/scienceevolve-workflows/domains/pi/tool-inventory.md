# 功能PI筛选：工具接入清单

首版需要文献检索、PDF解析和单体身份核查能力。先复用ScienceEvolve现有工具，确有缺口再用MCP Anything适配；不为普通Python算法逐项新增MCP。机理计算默认关闭。

| 能力／软件 | 对应工作 | 接入建议与当前边界 |
|---|---|---|
| 文献检索，OpenAlex／Crossref等 | 论文、题录、来源线索及最终候选核查 | 优先复用现有检索工具或API；保存查询、日期、来源和覆盖缺口。题录不等于已取得全文，当前未在目标实例验证连接。 |
| MinerU等PDF解析服务 | 读取正文、SI、表格和页码定位 | 优先现有服务；缺接口再封装提交、状态、结果。本轮未部署MinerU，解析完成仍需样品及原页复核。 |
| PubChem | 单体名称、CAS和结构身份线索 | 适合窄查询接口；返回来源、CID、结构和歧义，不凭名称猜SMILES。本轮未部署PubChem MCP。 |
| Zotero | 已有文献库及附件管理 | 可选；已有库才接，无库用文件清单。 |
| WebPlotDigitizer | 从曲线获取带定标依据的点列 | 人工辅助导出并保存项目；不假设稳定的全自动API。 |

上述能力可由现有工具或用户提供的可追溯文件满足，表中软件不是本包附带的运行服务。工作流`mcpServers`留空；接入前应实际发现工具并做小例子调用，不能编造工具名。

## 机理计算开启后再考虑

| 软件 | 启用前提 | 边界 |
|---|---|---|
| Packmol | 已有合格分子坐标，需要构建装填初态 | 可适配CLI；不负责PI建链、拓扑或力场参数化。 |
| LAMMPS | 目标确需MD，且结构、拓扑、力场、协议、预算均齐 | 复用异步作业设计。现有受限LJ演示不是PI Tg服务；正式材料输入须独立验证。 |
| CP2K | 明确的量子计算或参考标签需求 | 后置，不能只因没有经典力场就自动展开计算。 |
| DeePMD-kit／DP-GEN | 力场不足，且有合格标签与独立预算 | 后置；原子势标签是能量、力、应力等，不是Tg或T5。 |
| OVITO | 轨迹中确有需要人工核验的结构问题 | 作为可选检查及文件导出；不要求为所有轨迹分析新建MCP。 |

长计算采用提交、查状态、取结果与取消；保留任务ID、输入哈希、版本、日志和实际产物。软件连通只证明调用链，不能替代方法和材料科学验收。

## 直接使用Python的部分

证据去重与样品关联、单位和删失处理、RDKit描述符、候选枚举、SQLite存储、scikit-learn／LightGBM／Optuna、分组验证、不确定性与适用域、Pareto及主动学习选点、图表和报告导出。领域逻辑仍需实现或复用，但本轮不把它们逐一变成MCP，也不声称已完成研究算法。

## 新增接口的最小真实验收

- 检索：已知论文、无结果、分页与范围限制；输出来源及查询时间。
- PDF：真实原PDF与解析结果抽查，保留页码、图表与样品映射，失败不返回空成功。
- PubChem：已知化合物、无匹配、歧义三类；规范结构处理由RDKit完成，身份有效不保证合成可行。
- 计算：合格小算例、非法输入、超时、取消和断开重连；PI性质还须单独验证力场与协议。
