# 自愈合粘结剂需要哪些工具

本方向首先需要可靠的文献和实验文件交接。原PDF以低成本、可重复的常规实验推进，未要求把仪器自动化或机理计算作为首版前提。

| 能力 | 是否考虑MCP | 本轮处理与验收边界 |
|---|---|---|
| 文献检索、题录与全文获取 | 优先复用已有服务 | 保存查询、来源、页/图/表与覆盖缺口。原PDF四篇文献为待核入口，不把题录当成已验证实验。 |
| PDF正文、表格和页码解析 | 有服务则复用；缺接口再适配 | 可选MinerU后端，但未在本轮部署。若要封装，采用提交→状态→结果并核对原页；解析成功不等于科学结论正确。 |
| 原料SDS、供应商说明读取 | 外部检索/读取能力可复用 | 商品组成不明时查确切产品、供应商、文档版本和成分；需登录时按已有授权，缺失则人工提供。未新增爬取或账号接入。 |
| Zotero | 可选 | 有组内文献库才接；没有库先用来源文件清单，不强制安装。 |
| 天平、光学观察、拉伸/剥离、涂布、电池测试 | 本轮不封控制MCP | 实验人员按SOP操作，导出数据和原始记录，Agent进行读取与比较。未验证接口不写成自动控制能力。 |
| UV-vis、EIS | 按实际条件人工补充 | 服务于具体问题和主张，不要求全部具备；EIS变化不单独代表本征离子电导或修复。 |
| 可选材料模拟/相互作用计算 | 有具体问题再选后端与接口 | 默认关闭。原文没有指定必需引擎，不为完整工作流强加LAMMPS/DFT。现有LJ演示不能算粘结剂预测能力。 |
| 单位/统计/曲线/对照/图表 | 普通Python工作节点 | 直接用现有分析环境，按项目要求不为每项统计另建MCP。 |

真正缺少外部接口时，复用已发布的[MCP Anything 0.3.0](https://github.com/tianyixian/mcp-anything-skill/releases/tag/v0.3.0)，先核真实软件/API、权限与版本，再实现和跑真实小例子。本清单为选择与接入建议，不表示以上候选MCP已经部署。

首版workflow的`mcpServers`留空，运行前绑定目标平台已配置的服务。可先使用人工提供的原文与导出文件，未覆盖的检索或实验项明确列缺口。
