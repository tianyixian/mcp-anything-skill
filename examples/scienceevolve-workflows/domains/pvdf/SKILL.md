# PVDF 湿纺工作流

围绕填料、后拉伸温度与拉伸比对 β 相及加工性能的影响，交付可追溯的证据、实际运行的分析记录和下一轮实验任务单。先审核既有研究，按 `intake → evidence → analysis → proposal` 推进。资料不足时仍交付补资料清单和可填写模板，状态保持 `needs_input`。

## 输入与产物

从 `inputs/pvdf/run-spec.json` 和 `inputs/pvdf/measurements.csv` 开始，读取其指向的旧模型代码及参数、论文/补充材料与实验记录。`source_files` 填相对于运行工作区的原始文件路径列表，`target` 由实验人员填写具体研究目标。需求说明中的相对路径不是已取得文件的证明。所述旧样本数、拟合优度和候选数值均为待核验转述；只有实际读取、运行后才能形成本次结果。

每阶段写 `outputs/pvdf/<stage>.json`，保留 `status`、`input_hash`、`version`、`results`、`evidence`、`warnings`、`next_step`。`input_hash` 为实际读取文件相对路径到 SHA256 的对象；没有输入时为空对象。来源证据记录 DOI/文件和页码、图表或实验记录位置。真实数据与演示材料分开，缺输入不生成伪装成实测的数据行。

阶段 `status` 仅取 `completed / failed / needs_input / needs_review / unsupported / skipped`。`completed` 只表示当前阶段交付完成，不等于科研验证完成；执行错误、缺资料、待复核、工具不支持与明确不适用分别使用相应状态，并写明原因与下一步。数据泄漏或输入冲突无法用现有材料修复时使用 `needs_input`，要求补充/纠正资料；工具不能完成该类任务时使用 `unsupported`。

## 必须保持的数据口径

- 湿纺、干喷湿纺、电纺、熔纺、片材与薄膜分别标记。仅有其他工艺数据时，结论只能是迁移假设。
- 填料 wt% 必须有分母；缺少 PVDF 质量/总固体/溶液质量口径时不直接合并。
- β 相比例、结晶度、压电响应分字段；FTIR 和 XRD 不同定义不直接平均。光谱公式前提不满足时不给强制百分比。
- 原文 `>95%` 保留原文、数值边界 95 和关系 `>`，不是精确 95.0，也不是 `>=95`。缺失响应留空；加工失败另存状态，不能填 β=0。
- 区分论文报告值、图中读数、模型计算和估计。初始 β 不同、制样历史不同，不能只凭最终 β 较高就宣称 CNC 的独立因果效应。
- 独立配液/纺丝批次、批内后拉伸子样、技术测点分别编号；同一批测三次不是三次独立制样。

Lee 2021 的样品条件及旧表 `95%→99%` 是待核查事项。优先追到原文图表与计算定义；未得到原始证据时维持 `needs_review`，不自行改值。分析分别展示包含/排除争议条目的影响。

## 分析与工具选择

外部能力优先复用文献检索与全文读取；Zotero 只有现成库和访问配置时才是可选输入。CSV 清洗、谱图处理、logit/scikit-learn、验证、随机化和绘图直接用普通 Python，不另包 MCP。PVDF 第一版没有明确分子模拟任务，不自行加入 LAMMPS、DFT 或设备控制。

有真实资料时先复现旧模型、比较简单基线，再决定是否需要复杂模型。按论文或独立批次分组；清洗规则、特征选择、预处理和调参不使用测试组信息。分别报告训练、交叉验证和真正独立的外部验证，组数不足就说明无法可靠估计。需求中的高 R² 不能冒充本次外部预测能力。

检查下界处理、测量方法、初始 β、填料项、跨工艺迁移和争议记录的敏感性。保留版本、依赖、种子、划分索引与逐样本预测。来源或代码错误最多返工两轮，仍无法解决时记录阻断，不降低标准换取成功状态。

## 人工实验交接

`run_spec` 中设备范围、浓度口径、预算、独立批次数、加工/测量放行阈值和性能目标必须来自实验人员、SOP 或明确研究目标。模板中的 `null` 表示未确定，不能按零处理。阈值在本轮观察前冻结，改变阈值要换方案版本。

任务单拆为：基准编号、配液、原液放行、成丝凝固、洗涤干燥留对照、分样和基线、后拉伸、结构表征、力学/加工评价、新批次验证。每步保存样品/批次/方案版本、设定与实际值、单位、状态、原因、原始文件、操作者和时间。

异常分支保留：原液不均、供液异常、成丝异常、基准漂移、拉伸滑移/断裂、谱图可疑、β 与力学/加工冲突、填料归因不清、模型失准。设备无效与材料加工失败分开；不以升压或继续提高倍率代替排障。实际操作由实验人员按 SOP 执行。

可执行任务单完成而实验未做时用 `status: needs_input`，在 `next_step` 明确写“等待实验人员回传原始测量与实际执行记录”。新数据到达后先核对质量并评价冻结预测，再决定更新模型，保留失败结果。只有独立批次真实验证通过，才能称“已验证窗口”。CNC 3 wt%、90°C、DR≈6 或 β≈99.3% 都不是必须达到的答案。

## 汇报口径

摘要先说交付了什么、实际验证了什么、还缺什么、下一步怎么做。区分软件/流程可运行与科学结论成立。原始附件是需求来源，不是新的实测证据；不要把候选工艺写成批准配方或把人工交接写成自动实验闭环。
